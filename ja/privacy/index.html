プライバシーポリシー

Meow Wishes · 2026年11月27日施行・最終更新

このプライバシーポリシーは、開発者でありデータ管理者であるManifiora（以下「私たち」）が、iOS向けゲーム「Meow Wishes: Cat Logic Puzzle」（以下「本アプリ」）およびこのウェブサイトのご利用にあたって、情報をどのように取り扱うかを説明するものです。ご質問がありましたら、hello.manifiora@gmail.com までお気軽にご連絡ください。

かんたんなまとめ

  • アカウント登録も、広告も、実際のお金での購入もありません。お名前、メールアドレス、連絡先をおたずねすることは一切ありません。
  • ゲームのセーブデータ（進行状況、にくきゅう、設定）はお使いの端末にのみ保存されます。私たちが受け取ることはありません。
  • パズルをより良くするため、Google Analytics for Firebase を使って匿名のゲーム統計（たとえば、どのステージが開始・クリアされたか）を集めています。
  • 本アプリがクラッシュした場合、修正のために Firebase Crashlytics から技術的なクラッシュレポート（個人的な情報は含みません）が私たちに送られます。
  • どちらも、「せってい」→「匿名の利用データを送る」からいつでもオフにできます。
  • トラッキングも広告識別子も使用せず、お客様の情報を販売することは決してありません。

1. 端末に保存される情報

進行状況を保存するため、本アプリは次の情報をお使いの端末にのみ保存します：クリアしたステージ、にくきゅう（ゲーム内コイン）とヒント、にくきゅうで解放したテーマ・クッション・アクセサリー、ねこたちの衣装、今日のプレゼントの連続受け取り日数、チュートリアルの状況、そして設定（BGM、効果音、バイブレーション、言語、利用データの送信）。このセーブデータが私たちや第三者に送信されることはなく、本アプリを削除すると消去されます。

言語の設定を「端末の言語」のままにしている場合、本アプリはゲームをその言語で表示するために、端末で優先されている言語を読み取ります。この処理は端末内でのみ行われます。

2. 利用統計 — Google Analytics for Firebase

ゲームがどのように遊ばれているかを把握し、改善するため（たとえば、難しすぎるステージを見つけるため）、本アプリは Google のサービスである Google Analytics for Firebase を使用しています。記録するのは、ごく限られたゲーム内イベントです：本アプリの起動と表示した画面、ステージの開始・クリア（ステージ番号、かかった時間、ヒントを使ったかどうか）、ヒント・今日のプレゼント・にくきゅうで解放または使用したアイテム、イントロの完了、そして言語の変更。

これらのイベントとあわせて、Google Analytics は次の技術情報も受け取ります：本アプリのこのインストールのために Firebase が作成するランダムな ID、端末のモデル、OS と本アプリのバージョン、言語、そして国または地域（IP アドレスから推定されますが、Google Analytics は IP アドレスを保存しません）。お名前、メールアドレス、連絡先、セーブデータは受け取らず、本アプリは広告識別子（IDFA）を含まずにビルドされています。Google Analytics の広告機能はオフになっており、これらのデータが広告や、他社のアプリをまたいだトラッキングに使われることはありません。

利用統計は、「せってい」→「匿名の利用データを送る」からいつでも停止できます。

3. クラッシュレポート — Firebase Crashlytics

本アプリがクラッシュしたり重大なエラーが起きたりした場合、問題を見つけて修正するため、Google のサービスである Firebase Crashlytics からクラッシュレポートが私たちに送られます。レポートに含まれるのは技術的な情報のみです：エラーの内容と、本アプリのコードのどこで発生したか、端末のモデル、OS と本アプリのバージョン、その時点の端末の状態（空きメモリや画面の向きなど）、クラッシュの発生時刻、ランダムなインストール ID、そしてクラッシュ直前に発生した、前のセクションで説明したゲーム内イベント。

クラッシュレポートには、お名前、メールアドレス、連絡先、セーブデータ、広告識別子は一切含まれません。クラッシュレポートは本アプリを安定して動かすためだけに使用します。同じ「せってい」のスイッチ（「匿名の利用データを送る」）でオフにできます。

4. サーバーから届くアプリ設定 — Firebase Remote Config

本アプリは起動時に、Google のサービスである Firebase Remote Config からいくつかの設定（たとえば、本アプリの新しいバージョンがあるかどうか）をダウンロードすることがあります。このために Firebase は上記のランダムなインストール ID を使用します。個人情報は送信されません。

5. 収集しない情報

本アプリには、アカウント、サインイン、チャット、ソーシャル機能、ユーザー投稿コンテンツ、プッシュ通知、広告、アプリ内課金はありません。にくきゅうは遊んで集めるもので、購入することはできません。本アプリは App Tracking Transparency（アプリのトラッキングの透明性）の許可を求めず、位置情報、連絡先、写真、カメラ、マイク、ヘルスケアや金融に関する情報にもアクセスしません。

6. 共有と販売

私たちは個人情報を販売・貸与することはなく、私たち自身がデータを共有することもありません。本アプリからデータを受け取る唯一の第三者は、上記の Firebase サービスの提供者として私たちに代わって処理を行う Google です。本アプリのダウンロードに関するデータは、Apple が自社のプライバシーポリシーに基づいて処理します。法律で求められた場合には、情報を開示することがあります。

7. お子さまについて

本アプリは、成人向けの内容を含まない、一般の方向けの穏やかなパズルゲームです。13歳未満（またはお住まいの国でデジタル上の同意ができる最低年齢未満）のお子さまを対象としたものではなく、お子さまから故意に個人情報を収集することはありません。お子さまが個人情報を提供したと思われる場合は、私たちにご連絡ください。削除のお手伝いをいたします。

8. 保存期間と削除

  • ゲームデータは、本アプリを削除するまでお使いの端末に保存されます。私たちはコピーを一切持っていないため、お客様に代わって閲覧、復元、削除することはできません。
  • 利用統計は Google Analytics に最長14か月間保存されたのち削除されます。残るのは、インストール ID を含まない集計レポートのみです。
  • クラッシュレポートは Firebase Crashlytics に90日間保存されたのち削除されます。
  • お送りいただいたメールは、ご返信に必要な期間のみ保管し、通常は12か月を超えて保管することはありません。

9. お客様の権利

お住まいの地域によっては、たとえば EU一般データ保護規則（GDPR）、UK GDPR、米国の州のプライバシー法、トルコの個人データ保護法（法律第6698号、KVKK）などに基づき、ご自身の個人データへのアクセス、訂正、削除、利用の制限を求める権利、処理に異議を申し立てる権利、データポータビリティの権利、同意を撤回する権利、データ保護当局に苦情を申し立てる権利をお持ちの場合があります。私たちは、正しく動作し改善を続けるゲームを提供するという正当な利益に基づいて、利用統計とクラッシュレポートを処理しています（GDPR第6条1項(f)、KVKK第5条2項(f)）。これには、「せってい」のスイッチ、または私たちへのご連絡により、いつでも異議を申し立てることができます。30日以内にご返答いたします。

10. 国外へのデータ移転

Google は、EU の標準契約条項などの保護措置を講じたうえで、利用統計とクラッシュレポートを、米国を含むお住まいの国以外のサーバーで処理することがあります。

11. セキュリティ

ゲームデータがお使いの端末の外に出ることはありません。Firebase が収集するデータは、暗号化された通信（HTTPS/TLS）で送信されます。

12. このウェブサイトについて

このウェブサイトでは、Cookie、アクセス解析、広告を使用していません。ホスティング事業者（GitHub Pages）は、サイトの配信と不正利用からの保護のために、IP アドレスなどの技術データをサーバーログで処理することがあります。

13. 本ポリシーの変更

本アプリのデータの取り扱いが変わる前に（たとえば新しいサービスを追加する場合）、本ポリシーを更新します。ページ上部の日付が常に最新の版を示しています。
